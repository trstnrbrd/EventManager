# EventHub

A community event booking web application built with Django.  
Created as a course project by a BSIT student.

🌐 **Live Demo:** [reboredotristan.pythonanywhere.com](https://reboredotristan.pythonanywhere.com)

---

## About

Our professor asked us one question:  
*"If you could build a system to help the community, what would it be?"*

EventHub is my answer — a simple platform where people can discover local events and reserve a spot without the hassle.

---

## Features

- Browse and discover community events
- Reserve a booking slot for any event
- User registration and login (authentication required to book)
- Admin panel to manage events and bookings
- Responsive UI with smooth animations

---

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python 3.13, Django 5.1 |
| Frontend | HTML, CSS, Bootstrap 5 |
| Database | SQLite3 |
| Hosting | PythonAnywhere |
| Auth | Django built-in authentication |

---

## Project Structure

```
EventManager/

    ├── static/          # Images and static assets
    └── eventpr/         # Django project settings
```
